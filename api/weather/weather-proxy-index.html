🌤 Weather API Proxy

此页面作为天气 API 代理，所有请求经由此服务器转发至第三方接口。

GET /weather-proxy/?action=forecast
转发至 Open-Meteo Forecast API
参数：latitude longitude current daily timezone forecast_days
GET /weather-proxy/?action=search
转发至 Open-Meteo Geocoding API
参数：name count language format
GET /weather-proxy/?action=reverse
转发至 BigDataCloud Reverse Geocoding API
参数：latitude longitude localityLanguage

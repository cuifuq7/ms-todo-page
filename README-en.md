#### 🎯 Smart Sync, Seamless Switching

2. **Intelligent conflict resolution:** Timestamp-based smart merging keeps your data safe.

## 🚀 Get Started

### 🧩 Installation

**Option 1: Chrome Web Store (Recommended)**  
- Visit the [Chrome Web Store]([https://chromewebstore.google.com/](https://chromewebstore.google.com/detail/ms-todo/icmnmeceeheemlmbmolfendmiieabiac))  
- Click **Install** and enjoy  

**Option 2: Manual Installation (For Developers)**  
1. Download the latest release.  
2. Open `chrome://extensions/`  
3. Enable **Developer mode**.  
4. Click **Load unpacked** and select the extension folder.

---

## 📖 Usage Guide

1. **First-time setup:** Click “Login” and authorize your Microsoft account.  
2. **Create tasks:** Use the input box to add new tasks or subtasks.  
3. **Manage lists:** Use the left sidebar to organize task lists.  
4. **Sync options:** Auto-sync runs in the background, or trigger manual full sync anytime.

## 🛠️ Technical Architecture

### Core Modules (`src/`)
├── main.js # Core application logic
├── main-ui.js # UI management
├── main-storage.js # Local data storage (IndexedDB)
├── main-sync.js # Sync engine with Microsoft Graph
├── main-offline.js # Offline functionality
└── api.js # Microsoft Graph API wrapper



### Tech Stack
- **Frontend:** Native JavaScript + jQuery  
- **Data Storage:** IndexedDB (local) + Microsoft Graph API (cloud)  
- **Build:** Chrome Extension (Manifest V3)  
- **UI:** CSS3 + Responsive Design
